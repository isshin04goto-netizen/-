# 商品分析ノート（TikTok Shop アフィリエイト向け）

紹介する商品が「稼ぎやすいか」を 0〜100 点・S/A/B/C ランクで評価するWebアプリです。
インストール不要で、`index.html` をブラウザで開くだけで動きます（スマホ対応）。

## できること
- 商品の登録・編集・削除（データはブラウザ内に保存）
- 総合スコアとランク、1件あたり報酬、想定月収の自動計算
- 項目別スコア（報酬 / 需要 / 競合の少なさ / 品質・信頼 / 動画映え）と、強み・注意点のコメント
- 並び替え・検索
- CSVの取り込み・書き出し（Excel / Googleスプレッドシートで編集可）
- スコアの重み付けを自分好みに調整

## スコアの考え方
| 項目 | 計算に使う値 | 満点の目安 |
|---|---|---|
| 報酬 | 価格 × 手数料率 | 1件 2,000円 |
| 需要 | 月間販売数 | 月 10,000件 |
| 競合の少なさ | 月間販売数 ÷ 紹介クリエイター数 | 1人あたり月 500件 |
| 品質・信頼 | 評価（★）× レビュー数による信頼度 | ★5・レビュー100件以上 |
| 動画映え | 自己評価 1〜5 | 5 |

想定月収は「紹介者1人あたり販売数の10%を自分が獲得できた場合」の目安です。

## CSVの形式
1行目に見出しを入れてください（列の順番は自由）。

```
商品名,カテゴリ,価格,手数料率,月間販売数,評価,レビュー数,紹介クリエイター数,動画映え,URL,メモ
毛穴吸引美顔器,美容,3980,20,4200,4.4,1820,60,5,,
```
