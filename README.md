# ショップ分析ノート（TikTok Shop アフィリエイト向け）

TikTok Shop アフィリエイトの「商品選び」と「売れている動画の研究」をするWebアプリです。
`index.html` をブラウザで開くだけで動きます（スマホ対応）。

## 商品分析
商品の価格・手数料率・月間販売数などから「紹介して稼ぎやすいか」を 0〜100 点・S/A/B/C で採点します。

| 項目 | 計算に使う値 | 満点の目安 |
|---|---|---|
| 報酬 | 価格 × 手数料率 | 1件 2,000円 |
| 需要 | 月間販売数 | 月 10,000件 |
| 競合の少なさ | 月間販売数 ÷ 紹介クリエイター数 | 1人あたり月 500件 |
| 品質・信頼 | 評価（★）× レビュー数による信頼度 | ★5・レビュー100件以上 |
| 動画映え | 自己評価 1〜5 | 5 |

CSVの取り込み・書き出しに対応しています（見出し: 商品名, カテゴリ, 価格, 手数料率, 月間販売数, 評価, レビュー数, 紹介クリエイター数, 動画映え, URL, メモ）。

## 動画分析
他のクリエイターの動画の数字（再生・いいね・コメント・保存・シェア）と台本（文字起こし）から分析します。

- **伸びスコア**: エンゲージメント率・保存率・シェア率・再生規模から採点
- **フックの型**: 問いかけ / 警告・否定 / ターゲット指定 / 驚き / ビフォーアフター / 数字 / お得・限定 / 比較
- **構成の分解**: 文ごとにフック・問題提起・商品紹介・ベネフィット・社会的証明・価格・CTAを判定し、秒数を推定
- **売れる型チェック**、**真似したいポイント**、**勝ちパターン**（スコア上位動画の共通点）
- **Claudeで深掘り**: claude.ai で公開した版では、ページ内からClaudeに分析させられます（プランの利用枠内、APIキー不要）。ファイル版ではプロンプトをコピーして claude.ai に貼り付けます。

## データの保存先
- claude.ai で公開した版: アカウントに保存され、PCとスマホで同じデータを使えます
- `index.html` を直接開いた場合: そのブラウザの中に保存されます

## 開発
```
npm test        # スコア計算と動画分析のテスト
npm run build   # claude.ai 公開用の1ファイル版を dist/index.html に作成
```
